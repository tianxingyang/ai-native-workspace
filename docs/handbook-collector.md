# Private fixed Handbook collector
Reconstructed after workspace loss; new commit, not the original reviewed transport.
Only https://www.typescriptlang.org/docs/handbook/2/everyday-types.html is addressable. No model-supplied URL, query, headers, cookies, credentials, body, redirects or proxy delegation. GET over normally verified TLS, private Agent with empty proxy environment, IPv4 public-address checks before connecting, pinned lookup and actual socket peer check. IPv6 is deliberately unsupported. DNS mixed with reserved addresses fails closed.

Raw response limit is 512KiB; extracted evidence remains separately limited to 64KiB by the ledger. An earlier independent plain curl measurement by the coordinator saw 324,762 raw bytes, not a CoSeat live acceptance test. Tests use harmless mock documents. This collector performs no extraction or rendering, executes no HTML, fetches no subresources and records no receipts. MIME must explicitly be UTF8 text/html or text/plain, status200, uncompressed and complete; malformed UTF8 fails. One maximum8-second deadline covers DNS, connect and body. OS DNS itself cannot be cancelled, but late resolution cannot connect and late responses are closed.

Trusted dependency injection exists for offline testing only. This is not exposed through a tool, controller or external endpoint. No provider call or live CoSeat fetch was performed. Controller admission/cancellation integration, safe text extraction, ledger integration, and separate live TLS acceptance remain prerequisites. Do not treat fetched content as instructions.
