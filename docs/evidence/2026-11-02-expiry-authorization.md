## 相对 38 项基线新增 6 项

1. 配置拒绝旧控制版本、缺失／非法凭据期限；直接构造私有引擎也不能省略期限。凭据期限独立于 Grant。已过期但格式正确的配置可重新加载，过期成员仍拒绝，其他成员仍有效。
2. 真实 HTTP 路由矩阵：到期前 1 ms 的 owner 读取与 Worker 空闲轮询成功；到期时及后 1 ms，两个身份 × 11 类路由共 44 次均以 401 `credential_expired` 拒绝，无状态副作用。无效身份仍 401 `invalid_identity`，另一未到期成员不受影响。
3. 请求进入时凭据有效，空闲长轮询等待期间跨过截止，事务再次认证并拒绝，不能返回成功 idle 或领取工作。
4. 凭据仍有效但执行 Grant 到期时，空闲轮询拒绝；覆盖到期前、到期时、到期后及长轮询等待期间到期。其他成员的有效资源访问不受影响。
5. Run 的原绑定 Grant 过期后，读上下文、发布、确认认领、审批请求、事件（含 stopped）与未启动确认均拒绝；无结果或停止证据写入。Owner 自己仍有效的 read/cancel 授权可以取消并审计，Worker 没有到期善后例外，租约后来过期只显示 unknown。
6. 同一成员的其他资源 Grant 仍可读写、领取和发布；新同范围 Grant 不能替换旧 Run 的绑定授权，旧 Run 事件拒绝而独立资源读取仍可进行。

时间由测试注入控制端时钟，不改系统时钟，不靠实际等待授权到期；HTTP 长轮询仍运行真实异步等待。原 38 项全部保留，包含两种响应丢失、并发认领、取消竞态、SQLite 重启与备份，以及真实 SDK 工具循环。

## 切换与限制

- 控制配置 v1 不能直接启动本版本；需显式迁移 v2，并填入既有批准的绝对凭据截止时间，不能在升级时重新计时或延长。Worker 配置 v1、数据库 schema 1 不变。
- 本版没有到期报告豁免。到期之后即使运行实际已停止，拒绝的终态不能当作已确认停止；未结租约可能保留 unknown 并阻塞该成员新执行，需在期限内安排停止和对账。
- 未切换任何已运行服务；不得据此移除现有部署的独立到期保护。回退旧源码会重新引入期限缺口，需保留独立保护并审阅回退方案。
- fake 与真实 SDK＋模拟模型验证通过；本修复未验证真实模型调用、Linux 目标版本、真实网络与实际部署切换，不改变此前证据层级。
