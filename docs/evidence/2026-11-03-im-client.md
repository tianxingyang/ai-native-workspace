环境：Windows、Node 24.14.0、npm 11.9.0、Playwright 1.58.2 / Chromium 145.0.7632.6。只使用本次生成的本地临时身份、合成资料与 fake Worker，不调用真实模型。

浏览器覆盖：成员识别、普通消息、无 @ 研究认领/运行/完成、结果与合成来源、原消息筛选、运行中取消、取消响应为 `cancel_requested` 后收到 `executionSettled` 停止事件、丢失发送响应后同标识重试、连续提交不重复工作、断线自动恢复、刷新后重新认证读取历史、切换会话隔离草稿和待确认发送、无效凭据/只读/Grant 到期、输入法组合与 Enter/Shift+Enter、动态更新时的键盘焦点。

新增接口测试确认 `/session` 需要身份、凭据到期返回 401、隐藏未共享成员和无效范围，作用域信息复用服务端读权限。静态页面默认不在原私有入口启用；演示宿主校验 Host/Origin 和 CSP。页面凭据不进入 URL、localStorage、sessionStorage 或 cookie；测试不开启 trace/video。

## 仍有边界

- 浏览器是本地验证宿主，桌面框架/安装包仍待决定，未交付 Windows 客户端。
- 仅预配置授权会话/线程；无创建私聊/群组、任意父消息回复、附件、已读/未读、编辑撤回、持久登录、审批授权、真实研究或自动未知任务重跑。
- 使用轮询和有界 SQLite 试用存储，没有大规模负载测试；本 PR 不改原存储架构。
- `npm audit` 返回 3 个既有依赖问题（2 moderate、1 high），涉及固定 pi 1.4.0 及其 minimatch/undici 依赖链；新增 Playwright 不在该报告中。本切片未擅自升级已固定运行时，需独立兼容性/安全升级评估。不能称为 audit clean。
- 没有访问生产配置、令牌、服务、DNS/证书或修改原试点期限。所有本地演示进程及临时数据在测试结束关闭/清理。
