# VIT-128：语言机制与演示资源

本增量建立工程机制，**不决定产品默认语言、首批支持语言或市场，也不增加实际翻译支持**。共享界面和原生资源当前都只注册原有 `zh-CN` 演示；只有一个资源时隐藏选择器。合成的第二语言只出现在测试中，不随应用分发。

## 共享界面

`web/locales/registry.js` 静态注册内置资源、展示名称及明确的演示回退 ID。选择是当前页面内存状态，不读取浏览器语言、URL、远程语言包或持久偏好，不触碰身份凭据。未知初始偏好回到显式回退资源；用户请求未知 ID 则拒绝并保留当前选择。

`createLanguageRegistry` 为所有导入方保留稳定的 `text`/`format` 函数，选择切换后使用新资源。缺失的键或日期格式使用回退资源；非法值和参数占位符不匹配在注册时拒绝。格式缺失时采用回退格式选项，但仍按当前选择的 locale 格式化。两份资源都没有的键仍显式失败，不把键名或远端错误详情展示给用户。静态回退文字使用对应的 `lang` 属性。

`language-ui.js` 只绑定明确的界面文字节点和无障碍/提示属性，不扫描或替换用户内容中的相同字词。原地更新文字保留表单控件、值、勾选和焦点；DOM 绑定采用弱引用，不使已移除的会话节点或资料继续存活。动态讨论视图使用原始状态重绘，保留草稿、输入光标、会话选择、已展开来源及待确认请求标识。切换不连接、重发、改写授权或写阅读回执。显示时间变化不改原始时间戳、期限、按天分组或剩余时长算法。

普通讨论线程沿用主干的父会话授权与独立消息、草稿和创建请求。创建弹窗、待确认状态、父会话导航及线程说明参与文案切换；切换不触发创建或重试。固定展示槽的回调只捕获所需展示值，退出或最后一个阅读授权结束时移除旧绑定，关闭编辑弹窗时也清理按钮绑定，避免隐藏节点继续保留会话或已提交编辑内容。

## 原生与安装资源

`src-tauri/locales/manifest.json` 显式记录 `mode: demo`、`selected`、`fallback` 和本地资源文件白名单。Rust 和 Node 使用相同的缺失键回退规则；未知选择、重复注册、路径穿越、外部路径、非法资源值和不完整回退资源均拒绝。

Rust 构建确定性生成当前菜单、tooltip、窗口标题和通知文案。只读 `desktop_presentation` 命令返回编译时选定语言；网页启动先核对并锁定该语言。未注册或无法核对时禁止连接演示。**原生语言变更需要修改已审定的编译配置、重新构建并重启；本增量不实现运行时原生菜单切换。** 通知 XML 仍只转义文字节点，通知授权与导航协议不变。

安装窗口标题及短说明继续由 `npm run desktop:resources` 从选定资源同步到 Tauri 配置。`npm run check:desktop-resources` 不写文件，并校验选定原生 ID、共享 ID 和格式 locale 一致；npm 构建和 Rust 构建拒绝配置漂移。Tauri 的产品名/版本/标识、安装模式及 NSIS `SimpChinese`、`English` 和关闭语言选择器的设置保持原值。现有 NSIS 内置安装文字不代表新增了对应产品语言；最终语言及 NSIS 映射、安装界面文字验收要在产品决策后完成，不自动从网页选项推导。

## 验证与尚待决策

- 单元测试覆盖资源快照、注册白名单、未知偏好、缺失键/格式回退、占位符契约、桌面锁定、安装资源生成及配置保留。
- 测试专用合成长文案覆盖 320/390px、页面 `lang` 与日期格式、草稿及光标、管理表单、待确认发送、历史阅读回执、退出后的内容清理和桌面语言不匹配。
- 线程集成覆盖 320/390px 创建弹窗光标、父/子草稿隔离、待确认请求的同标识手动重试、父授权撤销，以及退出/仅剩管理权限后的固定展示槽清理。
- 同步恢复集成验证：当前授权同步成功前，切换语言仍不显示隔离中的恢复正文、不更改保存的检查点或发送请求；成功同步后的撤回和新正文按原权限呈现。
- 实际支持语言、默认语言及市场由 VIT-101/父项决定；决定后仍需验证实际翻译、混合回退、无障碍读音和更完整的本地化布局。工程机制通过不能替代产品语言验收。
- 真实安装、托盘和系统通知实测属于 VIT-124；本任务不运行安装程序、不发布安装包、不修改许可证。
