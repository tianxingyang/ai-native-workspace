# 可复用 IM 界面与本地演示

本切片已整合 main 的 `1f8408a70e32652995e4f050ee09c3f6834fd523`，包含 PR #2–#4 的后端、IM、桌面及后续审计/取消/通知修复。团队会话是主入口，人和 Agent 使用同一消息流；研究状态、结果、来源和取消回执附着于原消息。当前演示界面使用中文，目标市场、默认语言和首批支持语言尚未决定；当前只有模拟执行和合成资料。

浏览器提供共享界面的本地演示和回归宿主。Windows Tauri 安装客户端已复用 `web/app.js` 和 `web/style.css`；`web/client.js` 保留独立连接边界。桌面安装、托盘和通知的实现及实测限制见 [Windows 客户端说明](client-windows.md)。目前没有自动更新功能。

## 本地运行

需要 Node 24.x（>=24.14），在仓库根目录执行：

```sh
npm ci --ignore-scripts --registry=https://registry.npmjs.org --cache .npm-cache
npm run demo:im
```

终端给出回环地址和本地临时凭据文件路径。在本机打开该文件，把凭据粘贴到界面的连接表单。不要使用生产凭据。这里生成的身份只属于本次本地演示，与现有设备上的试点身份、期限和服务无关。

控制服务和独立出站 Worker 是两个进程，使用真实 HTTP、SQLite 与模拟执行器。示例提供“产品讨论 / 日常交流”和“研发讨论 / 插件协议”两个已授权范围。输入“请调研一下插件协议”会触发研究；普通聊天不会自动创建任务。演示执行故意等待约 5 秒，便于点击取消并观察真实停止回执。

Ctrl+C 提前关闭两端；演示最多 30 分钟，到期停止服务并删除临时数据库、身份文件与 Worker 目录。新启动是新的临时演示，不延长任何外部试点。页面刷新后重新输入本次凭据即可重新读取仍在运行的演示历史。

## 实现与边界

- 无新增生产依赖。原生 HTML/CSS/ES modules 由显式启用 `web` 的本地服务提供；原私有控制入口默认不启用网页。
- `GET /session` 只返回认证成员可读范围、该范围成员和当前动作到期时间，不返回令牌、完整 Grant 或其他会话。其余消息、运行、取消使用原接口。
- 控制配置 v2 显式指定每名成员的 `tokenExpiresAt`。所有请求沿用服务端身份及 Grant 检查，不因 UI 显示了按钮而获得权限。
- 令牌只驻留页面内存，不写 localStorage/sessionStorage/cookie/URL。刷新、退出和权限失败会清空页面状态。连接错误只显示固定安全文案，不回显请求体或秘密。
- 本地宿主校验 Host、Origin 与跨站请求，设置严格 CSP、no-store、no-referrer、nosniff。未开启 CORS、开放注册、权限授予或浏览器持久会话。
- 消息重试保留同一个 `clientEventId`；请求结果不确定时保留待确认条目并提示重试。重复点击不重复创建工作。此标识只在页面内存保存，未确认发送时刷新会提示可能丢失核对信息。
- 待确认发送可只读核对回执；重试前也先核对。发言权限消失但仍可阅读时，自动查询原发送结果，不重新发送。回执仅限认证成员在当前 scope 的原 `clientEventId`，返回编辑/撤回后的当前消息，不公开原发送指纹。查询为空只表示此刻未查到，不证明请求以后不会到达，因此保留待确认条目。阅读权限失效仍清空客户端状态；刷新丢失发送标识后的恢复仍需后续持久 outbox。
- 未确认的阅读位置也只在页面内存排队；切换讨论后继续重试原目标，不推进到后台新消息。刷新页面会丢失尚未送达的推进意图，重新打开讨论后可再确认；这不是客户端持久 outbox。
- 编辑或撤回对话框打开期间，新消息仍同步，但不推进本人阅读位置；此前已看过的阅读位置写入仍可重试。对话框关闭后，仅在消息流可见且位于底部时继续推进。会话切换快捷键和背景详情面板的 Escape 处理不穿透消息对话框，原生对话框仍处理 Tab 与 Escape。
- 打开长讨论时从第一条未读消息继续，以“新消息”分隔线标记本次打开时的未读起点；不会因打开就跳到末尾并推进整段阅读位置。切走再回来会恢复本页内的历史滚动锚点；若此前在底部且有未读消息，则从未读起点继续。“查看新消息”定位第一条未读，无未读时回到底部。滚动锚点随阅读授权失效或页面退出清除，不做跨设备持久滚动同步。
- 约 1.2 秒轮询恢复全部已授权讨论的消息与任务，网络中断时明确显示记录可能过时及上次同步时间；服务端给出的查看授权截止时间已过时按到期处理，不无限重试。不是 WebSocket 或完整游标补发实现。
- 会话列表显示最新消息预览、Agent 调研中状态，以及本人阅读位置之后其他成员的消息数（不计已撤回或失效消息）。本人阅读位置保存到服务端，重新连接或另一客户端使用同一身份可恢复；旧设备的迟到请求不会使位置倒退。消息流可见且位于底部时自动推进，隐藏页面、查看旧消息或窄屏详情遮挡时不推进。写入暂时失败会在后续同步重试，未确认前不能保证另一设备立即恢复。这里只表示本人浏览位置，不公开其他成员的已读回执，也不表示 Agent 已评估、接单或完成。
- 输入框上的席位卡显示本人在当前讨论“出席”或“列席（只读）”及发言授权截止时间，到期前 5 分钟提示；授权失效后输入区折叠，并说明“已于某时到期”“已被收回”或“没有发言授权”。成员面板只显示本人权限，不显示他人授权。这些都是展示提示，每项操作仍由服务端校验。
- 取消受理与实际停止独立呈现。只有服务端停止事件的 `executionSettled` 或未启动证据才显示对应确认；unknown 不自动重跑，failed 不提供伪装成安全恢复的按钮。
- 合成来源地址使用 `.invalid`，展示原始标题、摘录、占位地址与限制，故意不作为可点击真实证据链接。
- 当前线程来自已有授权范围。可回复同一范围内可读的消息；“查看讨论”列出根消息、逐级回复及各消息触发的调研进度和结果。回复只保存父消息 ID，引用随原消息编辑、撤回或结果失效更新，不存储引用正文副本。人和 Agent 使用相同接口与权限检查。
- 回复重试同时固定 `clientEventId` 与父消息 ID；已成功发送的回复即使父消息随后撤回也能核对原发送结果。新回复遇到父消息撤回会被拒绝，界面允许取消引用并保留草稿。待确认的网络失败不自动改写为普通消息。引用草稿随会话隔离，阅读权限失效时清除。
- 可编辑或撤回自己的消息，使用版本号避免覆盖其他设备的修改。上下文变更使旧运行和结果失效；确认旧执行停止后才重建，不能确认时保持 unknown。调研进度只来自服务端记录的运行事件。
- 编辑/撤回响应丢失后，重试先只读核对本人该次变更；仅失去发言权时自动核对一次，不重新提交。回执确认操作已收到，不等同于研究已应用；消息若随后再被修改，显示当前版本。查无记录仍保持待确认，恢复发言授权后显式重试使用原变更 ID。核对信息只留在当前对话框内存，返回讨论或刷新会丢失该 ID；不代表持久变更 outbox。
- 尚不支持新建会话/授权线程、私聊、附件、审批授权或跨设备持久登录；回复关系不创建新的授权范围。
- 可查找当前讨论已同步的消息正文，按不区分大小写的字面子串匹配，最新在前，每次显示 50 条并可展开更多；点击结果定位原消息。编辑后的正文随同步更新，撤回或失效结果不参与匹配。查询与结果只保留在打开的面板，关闭、切换会话、退出或失去阅读权限时清除。断网时只查已有快照，不是跨会话、服务端全文或来源附件检索。

## 语言资源分离进度

`web/locales/zh-CN.js` 保存当前演示的运行状态、通用错误提示、成员类型、相对日期标签、时长文案及日期格式；`web/presentation.js` 负责文本参数替换和按资源 locale 格式化日期。原始时间戳、授权期限判断、按天分组和向上取整时长仍由业务逻辑决定，展示层不修改它们。页面 `lang` 与当前资源一致；资源通过固定静态路径提供，不从 URL 或网络下载任意语言包。

静态 HTML 的文字和无障碍标签已使用显式资源标记；默认演示回退文案与资源的一致性由测试检查。初始化只绑定叶子文字节点及 `aria-label`、`placeholder`、`title`，不替换富内容、表单值或按钮图标。连接、编辑弹窗初始文案、输入占位和桌面桥接界面的相关动态覆盖也使用资源；运行状态变化仍由各自渲染函数负责，不在运行中重新初始化整个页面。

运行进度、取消操作、状态播报和合成结果的来源说明已复用资源，时间线与讨论详情使用同一套文案。收到输入与实际应用、取消受理与停止证据、完成状态与发布回执仍分别判断；文字模板不改变运行状态，也不改写用户正文或来源数据。占位来源地址保持纯文本。取消按钮可换行，避免较长资源文案在窄屏溢出。

发送及编辑/撤回的待确认、核对、重试和回执播报也使用资源；查无回执仍保留不确定性，核对不重发，显式重试仍沿用原请求标识。待确认发送按钮和变更弹窗支持较长文案换行，浏览器测试在 320/390px 验证只读核对、键盘焦点和恢复权限后的同一请求重试。

共享界面的会话、消息引用、查找、席位与权限提示也已迁入资源，包括桌面/浏览器各自的到期说明。业务中的授权期限、剩余时长计算、字面搜索和引用随原消息变化的规则保持不变。席位卡与权限面板允许较长标签换行，授权期限不再用省略号截断；引用预览保留正文宽度，较长取消引用按钮可另起一行。

这仍是**部分国际化**：桌面原生菜单和通知文案等仍待抽离；尚无语言切换入口或新增支持语言。品牌、示例发送正文和用户内容不在此次文案绑定范围内。当前中文资源保留既有演示事实，不是产品默认语言或市场决定。扩展文案测试只使用测试内替换资源，不进入产品配置。

纯展示层测试随 `npm test` 运行，也可单独执行 `npm run test:presentation`。浏览器覆盖长状态/错误/取消文案、纯文本呈现、日期提示及 320/390/1280px 布局；合成运行投影用于验证证据说明的展示分支，模拟执行器产出的来源数据用于验证两处详情的一致呈现。

## 验证

```sh
npm test
npm run check:web
# 首次需要测试用 Chromium；已有匹配浏览器时无需安装
npx playwright install chromium
npm run test:browser
```

浏览器测试使用临时身份，启动真实控制服务及独立 Worker，覆盖发送/回源、取消受理与停止回执、丢失响应重试、重复提交、断线恢复、切换会话、刷新重新连接、只读和授权到期，以及其他会话动态、讨论详情栏、到期提醒与列席折叠。新增逐会话阅读到期清理、卡住/延迟的会话响应不能恢复过期缓存、窄屏模态焦点与宽屏非模态切换回归。另有一项用模拟原生桥接运行桌面壳分支，不替代安装版 WebView2、托盘和系统通知验证。禁用 trace/video，转发请求失败只报告无认证头的诊断；先结束页面轮询再停止测试服务。截图保存在被 Git 忽略的 `.impeccable/review/`；截图只含合成成员和资料。

已知阅读期限由独立计时器约束本地缓存；断网或请求等待不会延长期限。到期会话的消息、预览、草稿和详情失去入口，仍有权限的会话保持可用。页面重新获得焦点或变为可见时也重新核对期限。客户端清理不授予任何权限，服务端仍逐请求鉴权。

## 桌面客户端后续决策

本机只读预检发现 Rust/Cargo 1.95.0、MSVC Build Tools 18 系列及 WebView2 156.0.4314.58；没有安装或改变系统组件。工具存在不是桌面打包验收。

若选择 Tauri，可复用当前界面，但仍需验证 Rust target/Windows SDK 与构建、限定桌面网络桥接目标、窗口生命周期、退出清理、包签名/安装体验。现有网页凭据内存策略不能直接演变为持久桌面令牌库；任何持久凭据机制、外网连接或新的访问授权都需另行确认。初次桌面验收应继续使用本地临时身份与相同后端权限，不加载远程网页作为拥有原生能力的界面。
