# 可复用 IM 界面与本地演示

本切片依赖 PR #2 的 `c080a2faada1d688b684973a7b7d8a31cf8ec1cc`。中文团队会话是主入口，人和 Agent 使用同一消息流；研究状态、结果、来源和取消回执附着于原消息。当前只有模拟执行和合成资料。

浏览器是这次本地验收的运行宿主，不是“产品只做网页”的决策。Windows 桌面客户端是后续入口方向，桌面框架和交付范围未定。`web/client.js` 是独立 HTTP 连接边界，`web/app.js` 和 `web/style.css` 可由桌面壳复用。本 PR 没有安装器、托盘、通知或自动更新功能。

## 本地运行

需要 Node 24.x（>=24.14），在仓库根目录执行：

```sh
npm ci --ignore-scripts --registry=https://registry.npmjs.org --cache .npm-cache
npm run demo:im
```

终端给出回环地址和本地临时凭据文件路径。在本机打开该文件，把凭据粘贴到界面的连接表单。不要使用生产凭据。这里生成的身份只属于本次本地演示，与现有设备上的试点身份、期限和服务无关。

控制服务和独立出站 Worker 是两个进程，使用真实 HTTP、SQLite 与模拟执行器。示例提供“产品讨论 / 日常交流”和“研发讨论 / 插件协议”两个已授权范围。输入“请调研一下插件协议”会触发研究；普通聊天不会自动创建任务。演示执行故意等待约 5 秒，便于点击取消并观察真实停止回执。

Ctrl+C 提前关闭两端；演示最多 30 分钟，到期停止服务并删除临时数据库、身份文件与 Worker 目录。新启动是新的临时演示，不延长任何外部试点。页面刷新后重新输入本次凭据即可重新读取仍在运行的演示历史。

## 实现与边界

- 无新增生产依赖。原生 HTML/CSS/ES modules 由显式启用 `web` 的本地服务提供；原私有控制入口默认不启用网页。
- `GET /session` 只返回认证成员可读范围、该范围成员和当前动作到期时间，不返回令牌、完整 Grant 或其他会话。其余消息、运行、取消使用原接口。
- 控制配置 v2 显式指定每名成员的 `tokenExpiresAt`。所有请求沿用服务端身份及 Grant 检查，不因 UI 显示了按钮而获得权限。
- 令牌只驻留页面内存，不写 localStorage/sessionStorage/cookie/URL。刷新、退出和权限失败会清空页面状态。连接错误只显示固定安全文案，不回显请求体或秘密。
- 本地宿主校验 Host、Origin 与跨站请求，设置严格 CSP、no-store、no-referrer、nosniff。未开启 CORS、开放注册、权限授予或浏览器持久会话。
- 消息重试保留同一个 `clientEventId`；请求结果不确定时保留待确认条目并提示重试。重复点击不重复创建工作。此标识只在页面内存保存，未确认发送时刷新会提示可能丢失核对信息。
- 约 1.2 秒轮询恢复消息与任务，网络中断时明确显示记录可能过时。不是 WebSocket 或完整游标补发实现，暂不提供未读/已读回执。
- 取消受理与实际停止独立呈现。只有服务端停止事件的 `executionSettled` 或未启动证据才显示对应确认；unknown 不自动重跑，failed 不提供伪装成安全恢复的按钮。
- 合成来源地址使用 `.invalid`，展示原始标题、摘录、占位地址与限制，故意不作为可点击真实证据链接。
- 当前线程来自已有授权范围；“查看讨论”筛选源消息与关联研究，不支持任意回复父消息、新建会话/线程、私聊、附件、编辑撤回、审批授权或跨设备持久登录。

## 验证

```sh
npm test
npm run check:web
# 首次需要测试用 Chromium；已有匹配浏览器时无需安装
npx playwright install chromium
npm run test:browser
```

浏览器测试使用临时身份，启动真实控制服务及独立 Worker，覆盖发送/回源、取消、丢失响应重试、重复提交、断线恢复、切换会话、刷新重新连接、只读和授权到期。禁用 trace/video，避免记录请求认证头。截图保存在被 Git 忽略的 `.impeccable/review/`；截图只含合成成员和资料。

## 桌面客户端后续决策

本机只读预检发现 Rust/Cargo 1.95.0、MSVC Build Tools 18 系列及 WebView2 156.0.4314.58；没有安装或改变系统组件。工具存在不是桌面打包验收。

若选择 Tauri，可复用当前界面，但仍需验证 Rust target/Windows SDK 与构建、限定桌面网络桥接目标、窗口生命周期、退出清理、包签名/安装体验。现有网页凭据内存策略不能直接演变为持久桌面令牌库；任何持久凭据机制、外网连接或新的访问授权都需另行确认。初次桌面验收应继续使用本地临时身份与相同后端权限，不加载远程网页作为拥有原生能力的界面。
